# v2 브라우저 회귀 확인

2026-10-27, Chrome 원격 브라우저의 실제 웹 UI로 아래 시나리오를 실행했습니다. 사이트 소유자 로그인 뒤의 배포 환경은 별도이며, 이 검증은 로컬 프리뷰입니다.

| 시나리오 | 확인 결과 |
| --- | --- |
| 기본 모델로 시작 | 모델 이름·두 클래스 연결됨 |
| 회색 단색 PNG 업로드 → 네 칸 확인 → 분석 | 빈자리0·사용중0·확인필요4, 추론 확률 대신 품질 사유 표시 |
| A1과 같은 좌표를 A2로 입력 → 영역 적용 | 대화상자 유지, 같은 영역 오류 안내, 기존 설정 보존 |
| 실제 전체 사진 예제 → 분석 | A1·A4 빈자리, A2·A3 사용중, 빈자리2개 |
| 분석 시작 직후 취소 | 취소 안내, 부분 결과 미반영 |
| 취소 후 다시 분석 | 워커 재로딩 후 정상 완료 |
| 동일 사진에 정답 저장 → 재분석 → 다시 저장 | 사진1장·기록1개 유지, 수정 안내 |
| 평가 CSV 다운로드 | 4행·사진해시1개, 분석/저장 시각 분리, 모델해시·ROI·전처리 포함 |
| 주차장 프로필 저장 | 이름으로 설정 저장, 선택 목록에 표시 |
| 320px·390px iframe 레이아웃 | 가로 넘침 없음(320px iframe 내부305px 동일 scrollWidth/clientWidth) |

일반 이미지 영역은 세로 스크롤을 허용하고 영역 편집 중에만 터치 드래그를 우선합니다. 키보드 탭과 대화상자 이름 속성, 상세 보기 후 포커스 유지도 구현했습니다.

단위 회귀: `npm test`(39개), Python 데이터/평가 검사14개. 워커 전송·취소·재시도·시간 초과·해제는 가짜 워커 계약 검사와 실제 모델 전처리 비교로 검증했습니다. 브라우저에서 실제 모델·사진 추론도 확인했습니다.

실제 iPhone Safari·Android 기기 성능, 사용자 현장 주차장 사진, 공유받은 팀원 계정 접속은 이 검증에 포함되지 않습니다. 물리 기기나 계정 없이 완료됐다고 간주하지 않습니다.

다음 변경 시 같은 순서로 다시 실행하고, 분석 시간·모델 버전·브라우저 버전·회귀 결과를 갱신하세요. 모델을 변경할 때는 별도 촬영일의 새 최종 시험자료를 준비하세요.
