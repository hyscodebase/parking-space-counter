# 주차칸별 차량 수 합산 진단

- 사진 20장 · 주차칸 559개
- 기존 v2 모델·판정 기준85% · 모델 변경 및 재학습 없음
- 칸별 정답 551/559 (98.57%)
- 불확실 없이 차량 수까지 정확한 사진 13/20
- 확정 차량 수가 정답과 같은 사진 17/20 (확인 필요가 있는 경우 정확한 대수 확정과 다름)
- 차량 수 범위에 정답 포함 17/20
- 빈칸→차량 오류 3칸, 차량→빈칸 오류 0칸
- 확인 필요 5칸 (그중 실제 차량 0칸)

## 사이트 예제
`UFPR04_2012-12-27_13_05_09`: 지정 28칸, 실제 차량 3대. 확정 차량 3대·확인 필요 1칸이므로 화면에는 3~4대 범위로 안내해야 합니다.

## 범위와 한계
이전에 관찰한 공개 PKLot 사진에서 평가 영역을 네 칸에서 전체 주석 칸으로 확대한 진단입니다. 새로운 독립 최종 시험이나 실제 현장 정확도 보장이 아닙니다. 예제 사진을 먼저 검사한 뒤 촬영시각순으로 진행하며, CPU240초 예산을 넘은 프레임에서 중단합니다. 성능을 보고 유리한 사진을 선택하지 않았습니다.
지정한 칸 밖의 차량은 세지 않으며, 한 칸에 차량 한 대라는 가정이 필요합니다. 주차칸 위치를 먼저 정하고 각 칸을 기존 모델로 분류해 occupied를 합산합니다. 촬영 위치가 달라지면 영역을 다시 지정해야 합니다.
Pillow로 만든224×224 RGB와 브라우저 Canvas에는 작은 픽셀 차이가 있을 수 있습니다. 실제 브라우저의 예제 추론도 별도 확인해야 합니다.
