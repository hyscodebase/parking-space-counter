# Teachable Machine 모델과 차량 수 집계

기존 `빈자리 / 사용 중` 두 클래스 모델을 그대로 사용합니다. 주차칸별 예측 결과에서 `사용 중`만 더하며, 차량 수별 새 분류 모델이나 차량 위치를 찾는 탐지 모델을 추가하지 않았습니다.

## 기본 모델로 확인

사진 촬영·선택 → 주차칸 영역 추가 또는 같은 카메라의 프로필 불러오기 → 각 영역의 정렬 확인 → 분석 순서입니다. 애매한 칸은 확인 필요로 남기며 잘라낸 칸과 확률로 점검합니다.

영역은1~100개 지정합니다. 동일 물리 영역은 중복 지정할 수 없으며 크게 겹치면 경고합니다. 촬영 위치·각도·줌·사진 크롭이 바뀌면 영역을 다시 맞춥니다.

## 직접 학습한 모델

Teachable Machine 이미지 프로젝트에서 `빈자리`, `사용 중` 두 클래스로 학습하고 TensorFlow.js 형식으로 내보냅니다. 설정에서 공개 HTTPS 모델 URL을 입력하거나 압축을 해제한 `model.json`, `metadata.json`, 모든 `.bin` 파일을 함께 선택합니다. 클래스 이름이 다르면 두 상태와 대응하는 이름을 확인합니다.

기본 v2 모델은 공식 `@teachablemachine/image@0.8.3`을 Node CPU에서 실행해 학습했습니다. 웹 UI 학습 완료·내보내기에 성공한 것으로 표현하지 않습니다. 이번 차량 수 집계 변경에서 가중치·모델 카드·출처 기록·해시는 보존합니다.

추론용 모델 ZIP의 세 파일과 별도 전체 프로젝트 묶음의 `training/parking-v2-training-source.tm`을 구분합니다. `.tm`은 사진456장과 설정을 다시 여는 **학습 전 프로젝트**이며 **Open project from file → Train Model → 미리보기** 순서로 사용합니다. 완성 가중치가 들어 있는 프로젝트로 해석하지 않습니다.

## 자르기와 판정

좌표는 원본 사진 대비0~1 범위의 `x, y, w, h`입니다. 사각형 전체를224×224 RGB로 조정하고 공식 Teachable Machine의 `pixel / 127 - 1` 전처리를 적용합니다. 주변 칸의 차량이 들어오지 않도록 주차칸 전체를 포함시킵니다.

기본 판정 기준은 최고 클래스 확률85%입니다. 기준 미달·동률·품질 문제로 추론을 생략한 칸은 `확인 필요`입니다. 사용 중7칸·확인 필요2칸이면 **확인된 차량7대**, 범위 **7~9대**입니다. 애매한 칸을 확정 차량이나 확정 빈자리로 세지 않습니다.

높은 확률은 정답의 보장이 아닙니다. 단색·암전·과노출 검사는 주차장 사진인지 이해하는 별도 인식 모델이 아니므로 잘못 자른 영역이나 무관한 사진도 통과할 수 있습니다.

## 파일·개인정보·네트워크

사진과 로컬 모델 파일은 앱 서버에 업로드하지 않고 브라우저에서 처리합니다. 라이브러리는 `dist/vendor/`, 기본 모델은 `dist/models/parking/`에서 읽습니다. 외부 CDN을 실행 라이브러리로 사용하지 않으며 오프라인 설치를 보장하는 PWA는 아닙니다.

외부 모델 URL을 지정하면 해당 서버에서 모델 파일만 읽습니다. HTTPS와 CORS 접근이 필요하고 URL 내 인증정보는 허용하지 않습니다. 로컬 모델 파일 합계는250MB 이하입니다.

프로필은 현재 브라우저에 저장됩니다. 기기·브라우저를 바꾸면 자동으로 옮겨지지 않으므로 영역 JSON을 내보냅니다. 모바일 촬영 화면과 지원 형식은 기기에 따라 다르며 실시간 영상 추론은 제공하지 않습니다.

## 결과와 검증

분석 JSON에는 사진 식별 정보, 모델 버전·해시, 분석 시각, 영역, 기준, 주차칸별 결과, 품질 정보와 수량을 남깁니다. 같은 사진을 여러 독립 시험 표본처럼 중복 집계하지 마세요.

기존4칸 CSV 평가 도구와 새 가변 주차칸 JSON 집계를 구분합니다. 실제 카메라의 별도 정답 사진에서 칸별 정확도, 차량 수 일치율, 과다·누락 집계와 확인 필요 비율을 함께 확인합니다.

반응형 화면 확인이 모바일 실기기 검증을 대신하지 않습니다. iPhone Safari·Android Chrome의 촬영, 모델 로딩·추론 시간, 메모리와 취소 동작은 별도 확인이 필요합니다.
