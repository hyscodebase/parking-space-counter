# 데이터 준비와 모델 학습

이 프로젝트는 제안서의 고정 시점 사진 A1–A4 주차칸 분류 시제품입니다. 기본 학습 모델은 사이트에 포함되며, 학습 자료와 재현 코드는 별도 재학습 프로젝트 묶음에 제공됩니다. 화면의 예시 시연은 동작을 설명하는 데이터이며, AI 성능 평가 자료로 사용할 수 없습니다.

## 1. 원본 데이터와 정답 준비

제안서에 기재된 [Kaggle PKLot Dataset](https://www.kaggle.com/datasets/ammarnassanalhajali/pklot-dataset) 또는 [PKLot 연구진의 원본 안내](https://web.inf.ufpr.br/luizoliveira/research-interests/pklot/)에서 데이터 사용 조건을 확인하고 자료를 직접 준비합니다. 아래 일반 CSV 전처리 도구는 데이터 다운로드나 XML 라벨의 자동 변환을 수행하지 않습니다. 제공된 재학습 묶음의 수집 스크립트와 출처 기록은 별도 자료입니다. 사용 데이터의 라이선스와 출처를 보존하세요.

한 카메라의 고정 시점 사진에서 A1–A4를 정합니다. 사진마다 차량 유무를 확인하고, 사용할 주차칸을 감싸는 직사각형 좌표를 기록합니다. 주차선의 위치가 달라지는 카메라·시점에서는 좌표를 다시 지정해야 합니다. 회전된 주차칸은 직사각형에 주변 칸이 포함될 수 있으므로 학습과 실제 분석의 자르기 방식을 일치시키세요.

`tools/manifest.example.csv`를 복사하여 실제 파일명과 정답으로 바꿉니다. 예제의 파일은 제공되지 않으며 숫자 좌표는 형식 설명용입니다.

| 열 | 의미 |
| --- | --- |
| image | `--image-root` 내부의 이미지 상대 경로 |
| slot_id | 주차칸 이름. 시연과 평가에서는 A1, A2, A3, A4 사용 |
| label | `empty` 또는 `occupied`. `빈자리`, `사용 중`도 허용 |
| date | 촬영 날짜 `YYYY-MM-DD` |
| sequence | 연속 촬영 묶음의 고유 ID. 여러 날짜에 걸치면 동일 ID를 사용 |
| x, y | 주차칸 직사각형 왼쪽 위 위치. 정수 픽셀 좌표 |
| width, height | 주차칸 직사각형 크기. 정수 픽셀 단위 |
| lighting | 낮은 `day`, 야간은 `night`. `night`, `야간`, `dusk`, `twilight`, `새벽`, `황혼`은 제외 |

좌표는 EXIF 방향 보정을 적용한 사진 기준입니다. `lighting`을 생략하면 낮이라고 가정하고 경고하므로 반드시 직접 확인하세요. 날씨·그림자·차량 종류가 다양하도록 수집하고, 가림이 심하여 차량 유무를 확정할 수 없는 사진은 정답을 억지로 붙이지 않습니다. 학습용은 빈자리·사용 중 각각 150장 이상을 목표로 합니다. 전체 클래스 수뿐 아니라 각 날씨 안에서도 두 클래스가 포함되는지 점검합니다. 비 오는 빈자리·젖은 바닥·강한 그림자가 빠지지 않도록 클래스×날씨 수량표를 남기세요.

## 2. 날짜를 나누고 주차칸 자르기

Python 3.10 이상에서 저장소 루트를 기준으로 실행합니다.

```bash
python -m venv .venv
# macOS / Linux
source .venv/bin/activate
# Windows에서는 .venv\Scripts\activate
python -m pip install -r tools/requirements.txt
python tools/prepare_dataset.py --manifest data/manifest.csv --image-root data/raw --output data/prepared --seed 42
```

입력 원본 폴더와 출력 폴더는 서로를 포함하지 않는 별도 폴더여야 합니다. 출력 경로가 이미 비어 있지 않으면 실행을 거부합니다. 경로·라벨·중복·좌표를 모두 검증한 후 결과를 생성합니다.

같은 날짜의 모든 사진은 하나의 집합에만 들어갑니다. 같은 원본 전체 사진에서 자른 여러 칸도 항상 같은 집합에 둡니다. 날짜가 다른 연속 촬영이라도 `sequence` ID가 같으면 함께 묶습니다. 그룹을 시드 42로 섞어 기본적으로 검증 15%, 시험 15%, 나머지를 학습에 배정합니다. 비율은 사진 수가 아니라 독립 그룹 수 기준이며, 그룹 크기가 다르면 실제 사진 비율도 달라집니다. 최소 3개의 독립 날짜·촬영 묶음이 필요합니다. 가능하면 더 많은 날을 확보하고 각 집합의 클래스·날씨 구성을 확인하세요.

출력 폴더는 다음과 같습니다.

```text
data/prepared/
  train/empty/          # 학습에 사용할 사진
  train/occupied/
  validation/empty/     # 임계값·모델 선택용
  validation/occupied/
  test/empty/           # 최종 성능 확인용
  test/occupied/
  manifest.csv         # 원본·좌표·분할·잘린 이미지의 연결표
  summary.json         # 날짜별 분할, 클래스별 수량, 경고
```

각 주차칸은 224×224로 변환됩니다. 수량을 채우려고 사진을 복제하지 않습니다. `summary.json`에서 학습 클래스별 150장 미만, 검증·시험 클래스 누락 여부를 확인하세요. 날짜 분리를 깨면서 클래스 수를 맞추면 안 됩니다. 클래스 비율이 크게 다르면 학습 데이터만 줄이거나 추가 수집하고 검증·시험 원본은 유지합니다.

## 3. Teachable Machine 학습과 연결

[Teachable Machine](https://teachablemachine.withgoogle.com/)에서 이미지 프로젝트의 일반 이미지 모델을 생성합니다. 두 클래스 이름을 `빈자리`, `사용 중`으로 지정하고 각각 `train/empty`, `train/occupied` 사진만 올립니다. 학습 완료 후 TensorFlow.js 형식으로 내보냅니다.

제공된 기본 모델은 ‘기본 모델로 시작’으로 연결할 수 있습니다. 직접 학습한 모델은 웹앱의 모델 연결에서 호스팅 모델 URL을 입력하거나, 내보낸 `model.json`, `metadata.json`, 모든 가중치 파일을 함께 선택합니다. 모델 클래스 이름과 빈자리·사용 중의 대응을 확인합니다. 분석 사진과 모델은 별개입니다. 원본 `.tm` 프로젝트와 완성된 추론용 모델 ZIP도 구분합니다. `.tm`은 웹 학습 화면에서 원본 사진과 학습 설정을 다시 여는 용도이며, 완성 가중치는 모델 ZIP의 세 파일로 제공됩니다.

기본 모델은 Teachable Machine 공식 이미지 라이브러리를 Node CPU 환경에서 실행해 학습했습니다. 웹 UI가 응답하지 않아 실행 환경을 바꾼 경위와 파라미터는 모델 카드에 기록합니다. Teachable Machine 자체 학습 화면이나 공식 라이브러리 내부 검증에서 보이는 수치는 최종 시험 결과로 대신하지 않습니다. 학습에 넣지 않은 날짜의 검증 사진으로 모델과 임계값을 조정한 다음, 따로 남긴 시험 사진에 한 번 적용합니다. 동일 시험 집합을 반복해서 보며 재학습하면 그 집합은 더 이상 독립 시험 자료가 아닙니다.

## 4. 실제 모델 결과 평가

앱에서 실제 모델로 분석한 후 A1–A4의 정답을 입력하여 평가 기록을 저장한 뒤 평가 창에서 CSV를 다운로드합니다. 메인 화면의 분석 결과 저장은 현재 사진의 JSON을 내보내며, 같은 사진에 저장한 정답이 있으면 함께 포함합니다. 사진 SHA-256이 같으면 재분석 시 기존 평가를 갱신하며 독립 표본처럼 중복 누적하지 않습니다. 영역·판정 기준을 바꾸어 비교하는 실험은 별도 실험 기록으로 관리하세요. JSON의 기본 구조는 다음과 같습니다. 아래 값은 파일 형식 예시이며 성능 결과가 아닙니다.

```json
{
  "mode": "model",
  "records": [
    {"frame_id": "camera1-2026-10-15-001", "slot_id": "A1", "truth": "empty", "status": "uncertain", "confidence": 0.58, "source": "model"}
  ]
}
```

CSV의 첫 기본 열은 `frame_id,slot_id,truth,status,confidence,source`이며, 사진·모델 식별자, 실제 분석 완료 시각, 영역, 판정 기준, 전처리와 품질 정보가 추가됩니다. 과거 파일도 기본 열이 있으면 Python 평가 도구에 사용할 수 있습니다. `truth`는 사람이 확인한 `empty` 또는 `occupied`이며, `status`는 모델의 `empty`, `occupied`, `uncertain` 중 하나입니다. JSON 최상위 `mode`나 각 행 `source`는 반드시 `model` 또는 `demo`를 명시합니다. `demo` 행과 정답이 없는 행은 제외하며, 나머지 형식 오류는 거부합니다.

```bash
python tools/evaluate.py parking-results.json --output evaluation-report.json
python -m unittest discover -s tests -p 'test_*.py' -v
```

| 지표 | 의미 |
| --- | --- |
| accuracy_all_slots | 정답을 맞힌 칸 / 정답이 있는 전체 칸. 확인 필요는 오답으로 계산 |
| accuracy_decided_slots | 정답을 맞힌 칸 / 확인 필요를 제외한 칸 |
| coverage | 빈자리 또는 사용 중으로 안내한 칸 / 전체 칸 |
| false_empty_count | 실제 차량이 있는데 빈자리로 안내한 건수 |
| false_empty_rate_among_occupied | 위 건수 / 실제 사용 중인 칸 |
| empty_precision | 빈자리로 안내한 칸 중 실제 빈자리의 비율 |
| empty_count_exact_match_rate | 4칸 빈자리 수가 정확히 일치한 사진의 비율 |
| empty_count_mean_absolute_error | 사진별 빈자리 수 차이 절댓값의 평균 |

빈자리 수 지표는 동일 `frame_id`에 A1–A4 정답이 모두 있는 경우에만 계산합니다. `uncertain`은 빈자리로 세지 않습니다. 분모가 없으면 0으로 꾸미지 않고 `null`을 출력합니다. 빈자리 수가 우연히 같아도 개별 칸을 틀릴 수 있으므로 칸별 지표와 함께 확인하세요. 동일 사진을 반복 분석하여 여러 독립 표본처럼 계산하지 말고 대표 결과 한 개만 사용하세요.

## 5. 전체 사진 네 칸으로 검증하기

잘라낸 개별 칸 시험과 별도로, 촬영 날짜·연속 촬영을 분리한 실제 전체 사진을 준비합니다. A1–A4의 좌표와 정답을 각 사진에 기록하고, 실제 앱과 같은 사각형 자르기·224×224 전처리·품질 검사·판정 기준으로 분석합니다. 원본 사진을 한 번만 표본으로 세고 칸별 정확도, 네 칸 빈자리 수 일치율, 확인 필요 비율과 차량→빈자리 오류를 함께 보고합니다.

빈자리 수가 0·1·2·3·4칸인 상황과 날씨·그림자 조건이 평가에 얼마나 포함됐는지 표로 남깁니다. 확인하지 못한 조건은 결과를 비워 두거나 미검증으로 표시합니다. 개별 패치의 높은 정확도를 전체 사진의 집계 성능이나 다른 장소의 성능으로 대신하지 않습니다.

실제 적용할 주차장의 카메라 위치와 주차칸을 정한 뒤, 학습에 포함하지 않은 날의 사진으로 별도 시험합니다. 한 카메라에서 검증한 결과는 다른 카메라·장소를 자동으로 대표하지 않습니다.

## 6. 오류 분석과 품질 검사

우선 개선할 오류는 실제 사용 중인 칸을 빈자리로 안내한 경우입니다. 해당 사진의 가림·그림자·날씨·시점 차이를 기록하고 학습 사진을 보강하세요. 임계값을 올릴수록 확인 필요가 늘 수 있으므로 정확도와 coverage를 함께 보고 검증 집합에서 결정합니다. 단색·암전·과도한 노출 등의 명확한 품질 문제는 추론 전에 검사해 확인 필요로 처리합니다. 품질 검사는 주차장 여부를 의미적으로 판별하는 모델이 아니며, 모델의 높은 확률도 입력이 적합하다는 보장이 아닙니다. 실제 빈자리 crop을 과도하게 거절하지 않는지도 검증 자료로 확인하세요. 야간은 원래 제안서의 적용 범위에서 제외되며 야간 입력을 실제 주간 성능으로 설명하지 않습니다. 실시간 CCTV 운영 성능도 별도 시험이 필요합니다.

## 출처와 범위

- 원본 제안서: 고정 시점 사진 4칸, 이진 분류, 임계값 미달 확인 필요, 촬영 묶음 분리, 야간 제외.
- [PKLot 연구진 안내](https://web.inf.ufpr.br/luizoliveira/research-interests/pklot/): 데이터셋과 원 논문 확인.
- [Teachable Machine 공식 사이트](https://teachablemachine.withgoogle.com/): 이미지 분류 모델 학습과 프로젝트용 내보내기.

기본 모델과 제공 평가 결과의 정확한 데이터 구성·학습 방법·한계는 모델 카드와 배포 모델 보고서에서 확인합니다. 추가 수집 시 원본 경로·촬영일·카메라·날씨·SHA-256·라벨 검수 내용을 남기고, 재학습에 기존 시험 자료를 섞지 않습니다. 포함된 단위 테스트는 코드의 분할·계산·입력 검증을 확인하며 AI 정확도를 입증하지 않습니다.
