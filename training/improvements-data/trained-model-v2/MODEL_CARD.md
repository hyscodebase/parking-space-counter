# 빈자리 v2 모델 카드

Teachable Machine 공식 @teachablemachine/image0.8.3을 Node CPU에서 실행해 학습한 MobileNetV2 0.35 모델입니다. 웹 학습 화면에서 학습 완료한 모델로 표현하지 않습니다.

## 학습 데이터

공식 PKLot UFPR04 주간 사진456장(빈자리228장,사용중228장)을 제공했습니다. 각 클래스는 Sunny100장,Cloudy100장,Rainy28장입니다. 비 오는 빈자리의 실제 원본 확보량에 맞춰 사용중도28장으로 줄였으며 복제로 채우지 않았습니다. 공식 내부15%검증으로70장을 분리하여386장으로 가중치를 학습했습니다. 외부 검증·시험150장씩은 촬영일이 학습과 겹치지 않습니다.

50epochs, batch16, learning rate0.001, Dense100, RGB224×224, pixel/127−1.

## 검증 결과

| 평가 | 관측 결과 |
|---|---|
| 외부 검증 패치 | 149/150 정답 |
| 시험 패치 | 150/150 정답 |
| 같은 카메라 실제 전체사진 | 120/120칸 정답, 30/30사진 빈자리 수 일치 |
| 학습하지 않은 다른 시점/주차장 스트레스 시험 | 37/40칸 정답, 8/10사진 빈자리 수 일치 |

확신도 기준80%, quality-v1에서 측정했습니다. 전체사진은 합성 패널이 아닌1280×720실제사진의 고정된4개주차칸입니다. 목표카메라 시험은 빈자리0~4칸 상황별6장씩3일의 사진으로 구성했습니다. 실제발생빈도 표본은 아닙니다.

패치 시험은 날씨별50장(Sunny/Cloudy/Rainy각빈자리25·사용중25)입니다. 이전 모델도 같은 새 패치시험150/150을 맞혔습니다. 따라서 정확도가 개선됐다고 주장하지 않고, 비 오는 빈자리 학습 보강과 실제 전체사진 평가 증거를 추가한 것으로 해석합니다.

## 적용 범위·주의

품질 검사는 단색·암전 등 명백한 무효 입력을 거르는 보조 검사이며 일반적인 주차장 여부 판별기가 아닙니다. 다른 시점 시험은40칸중3칸을 틀렸습니다. 새로운 주차장·야간·가림·카메라 이동에는 현장검증이 필요합니다. 이전에 보았던 시험셋은 회귀 비교용이며 향후 모델 조정 후에는 새 날짜의 최종시험셋을 확보하세요.

원본 데이터는 CC BY4.0 PKLot(Almeida et al.,2015)입니다. 공식패치는 UFPR VRI에서 받고, 전체사진과XML유래bbox라벨은 고정커밋577e9c942e596819798d42fdc4d14d0b6646a43f의 dronefreak/PKLot 비공식미러를 사용했습니다. 출처·변경·해시는 DATA_README와각manifest에 있습니다.

## 파일

model.json, metadata.json, weights.bin을 함께 선택해 추론합니다. parking-v2-training-source.tm은456장의 학습소스와설정을 담은 재학습용프로젝트이며 완성가중치와는 별개입니다.
